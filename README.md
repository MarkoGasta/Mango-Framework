### What is it?
**Mango Framework** is my take on creating a professional and feature full, but still easy to use, framework to handle all scripts dor creating experiences on *Roblox*. While it might be similar to others, this framework has it's own style. The layout in the framework is straight forward and easy to learn. It's been revised over multiple years to handle anything you might need in a game. Depending on the branch you choose, it's functionality can range from only the essentials to a full set of integrated tools for speeding up development.

### Instructions
Installation and usage instructions can be found in the [documentation](https://markogasta.github.io/Mango-Framework-Docs/install/from_source/).

### Branch Info
**Barebones Branch** - Stripped of all extended features, this branch enables the user to build all of the systems from the group up.

### Disclaimer
This framework is still being developed which means that some of it's features might not be fully functional. For issues you might face, open an issue and report it. A fix might take some time to implement due to the framework development being intertwined with my tight work and school schedule.
